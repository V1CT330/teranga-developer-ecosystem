# Changelog

All notable changes follow the intent of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic versioning.

## [1.0.0] - 2026-08-21

### Added

- Signal Desk product shell with responsive navigation, searchable tool registry, themes, favorites, and local recent-tool history.
- Local browser engines for JSON, Base64, URL encoding, JWT payload reading, SHA-256, UUID generation, password generation, timestamp conversion, regular expressions, color inspection, controlled placeholder text, and basic HTML formatting.
- GitHub Actions for validation, static Pages deployment, releases, CodeQL analysis, and dependency monitoring.
- Product, privacy, architecture, deployment, roadmap, contribution, and security documentation.
