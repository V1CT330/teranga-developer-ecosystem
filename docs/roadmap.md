# Product roadmap

## Next local engines

The next development units are XML, CSS, JavaScript, SQL, Markdown, CSV, QR, image conversion, image resize, image compression, unit conversion, sitemap, robots.txt, and metadata generation. Each engine should remain browser-native where technically reasonable.

## Product operations

Future commercial work may add a dedicated documentation site, governed template gallery, public feedback workflow, package release cadence, accessibility checks, and a changelog discipline.

## Optional integrations

Account sync, team workspace data, customer billing, customer support, server-side APIs, analytics, scheduled processes, and payment handling are deliberately outside the static Pages release. Treat each as a separately scoped integration with its own provider, cost, security model, privacy copy, and customer-facing terms.
